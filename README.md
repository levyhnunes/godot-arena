# Arena

Um pequeno arena survivor top-down feito em Godot 4, construído aula por aula enquanto aprendo o motor.

## Como jogar
- **WASD / setas:** mover
- **Mouse:** mirar
- **Botão esquerdo:** atirar

Os inimigos surgem sem parar. Se um deles encostar em você, o jogo reinicia.

## Como rodar
Abra o Godot 4.7+, importe a pasta do projeto e aperte **F5**.
